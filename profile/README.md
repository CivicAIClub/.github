# Civic AI Club at Pomfret School

A student-run development team at Pomfret School. We build free tools that solve real problems for Pomfret faculty and local organizations.

Website: **https://civicaiclub.github.io**

Each project lives in its own repository. Faculty cases are named `case-<letter>-<slug>`; cases for local organizations are named `ext-<letter>-<slug>`.
